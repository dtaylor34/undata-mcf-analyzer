## 🐛 **Common Issues**

### Port 3000 already in use?
```bash
# Kill process on port 3000
npx kill-port 3000

# Or use different port
PORT=3001 npm start
```

### "react-scripts: command not found"?
```bash
npm install react-scripts
```

### Build fails?
```bash
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
npm start
```
